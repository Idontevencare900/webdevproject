How Cookies Work

What Is a Cookie?

Browser cookies refer to bits of information which are sent by the server of the visited website to the user's browser in order for them to be stored. The use of cookies is justified by the fact that the Hypertext Transfer Protocol (HTTP) is stateless and therefore, the server does not remember previous client requests. Upon the response, the server can provide a Set-Cookie header, and the browser will then send the cookie back to the server in a Cookie header (MDN Web Docs). The inventor of the cookie is Lou Montulli of Netscape (1994)

How Exactly Do Cookies Work?

Each cookie exchange is an interaction between the browser and the server. During the first visit, all that the browser does is send a request to the server asking for a web page. The server replies by sending the web page and a Set-Cookie header, indicating to the browser that it should set a cookie. Once the cookie has been set, the browser sends it back in a Cookie header during each subsequent request to the same server. To sum up, the server uses the Set-Cookie header to send the cookie, while the browser uses the Cookie header to return the cookie.

The Cookie Process: Simplified

  1. You visit a website and your browser sends a request to the website's server.
  2. The server replies with the web page and may include a cookie to store.
  3. Your browser saves the cookie on your computer.
  4. When visiting the website again in the future, your browser sends the cookie back to the server.

Controlling Cookies

Every cookie has a number of settings that controls how exactly it behaves
Setting What It Does
Name=Value The cookie’s label and the information it holds.
Domain Which website (and its subdomains) the cookie belongs to.
Path Limits the cookie to certain parts of a site
Expires The date the cookie is deleted.
Max-Age How many seconds until the cookie is deleted.
Secure Only sends the cookie over protected (HTTPS) connections.
HttpOnly Blocks JavaScript on the page from reading the cookie.
SameSite Controls whether the cookie is sent with requests from other websites.
