Key Concepts

These six ideas explain most of what you need to know about browser cookies. Each one builds on the others.

1. The Web Is Stateless

A web server sees each request as a completely fresh one. By default, the server does not know that you have already visited some other page on the website. To help solve this problem, cookies were invented.

2. Sessions

A session represents an interval of activity, including being logged in. Typically, the server provides you with a randomly generated ID that is stored by your web browser in a cookie. Each time, on receiving a request, the server looks for your data through this ID.

3. Cookie Security

Cookies may carry private data like the session identifier for logins, therefore they require security. Secure property will prevent a cookie from traveling via an insecure connection, whereas HttpOnly will not allow any script from the page to access it.

4. Cross-Site Tracking

If an advertiser plants cookies in many different websites, it can track you in all those sites and create a profile of your interests. This is one of the major privacy issues associated with cookies.

5. Consent

GDPR regulations require that most websites obtain permission from users before implementing any non-essential cookies. That is why cookie consent banners pop up when you visit a website for the first time.

6. Managing Your Cookies

You have complete control over the cookies that are stored in your browser. You can see them, delete them, and block specific ones in your browser’s privacy settings. Deleting cookies means you will be logged out of almost all websites, so be prepared to login again.
